# AquaVerse AI

AquaVerse AI is an intelligent water quality assessment platform that predicts water potability using machine learning and provides AI-powered advisory reports.

## Features
- Water quality prediction
- AI-generated water safety recommendations
- User authentication
- Interactive dashboard
- Downloadable advisory reports
- Firebase integration

## Tech Stack
- React
- TypeScript
- Vite
- Firebase

## Installation

```bash
npm install
npm run dev
```
